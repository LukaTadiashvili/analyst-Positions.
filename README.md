# 📊 ანალიტიკოსის ვაკანსიები

ქართული ვაკანსიების საიტებიდან ანალიტიკოსის პოზიციებს აგროვებს ერთ ცხრილში. აქვს ფილტრები, მოკლე შეჯამება, სტატისტიკა და ყოველდღიური შეტყობინება აიფონზე.
სრულიად უფასოა: მუშაობს GitHub Actions-ზე და GitHub Pages-ზე, შეტყობინებები მოდის ntfy-ით.

## რას აკეთებს

- **ყოველდღე 08:17-ზე** (თბილისის დროით) ამოწმებს 9 საიტს: jobs.ge, hr.ge, myjobs.ge, cv.ge, hh.ge, TBC-ის კარიერის გვერდს, openjobs.ge, unijobs.ge და joob.ge.

- ერთსა და იმავე ვაკანსიას, რომელიც რამდენიმე საიტზე დევს, **აერთიანებს ერთ ჩანაწერად**.
- თითოეული ვაკანსიიდან ამოიღებს: ხელფასს, დონეს (სტაჟირება / Junior / Middle / Senior), საჭირო გამოცდილებას, ენებს, ხელსაწყოებს (SQL, Power BI, Excel, Python…), მოვალეობებს, მოთხოვნებს და იმას, რასაც კომპანია გთავაზობს.
- თუ ახალი ვაკანსია დაემატა, **ntfy-ით შეტყობინებას** გიგზავნის.

## დაყენება (ერთხელ, ~10 წუთი)

1. **რეპოზიტორია.** შექმენი GitHub-ზე საჯარო (Public) რეპო, მაგალითად `analyst-Positions.`, და ატვირთე ეს ფაილები. ფოლდერები `site/`, `scraper/` და `.github/` რეპოს ძირში უნდა იყოს.
2. **Pages.** გახსენი Settings → Pages → *Build and deployment* → Source და აირჩიე **GitHub Actions**.
3. **შეტყობინებები.**
   - App Store-დან დააყენე უფასო აპი **ntfy**.
   - მოიფიქრე გრძელი, ძნელად გამოსაცნობი სახელი, მაგალითად `luka-analyst-jobs-7f3k9q`.
   - აპში დააჭირე **+** და გამოიწერე ეს სახელი.
   - GitHub-ში გახსენი Settings → Secrets and variables → Actions → *New repository secret*. Name იყოს `NTFY_TOPIC`, Value კი შენი მოფიქრებული სახელი.
4. **პირველი გაშვება.** გახსენი Actions → „ვაკანსიების შემოწმება“ → **Run workflow**. დაახლოებით 5 წუთში საიტი გაიხსნება აქ: `https://<შენი-username>.github.io/analyst-Positions./`
5. **აიფონზე დამატება.** გახსენი ეს ბმული Safari-ში → გაზიარება (□↑) → **Add to Home Screen**.

### (არასავალდებულო) „განახლების“ ღილაკი, რომ საიტებს ახლავე გადაამოწმებდეს

ღილაკი ყოველთვის ტვირთავს უახლეს უკვე შენახულ მონაცემს. რომ ღილაკმა საიტების ხელახლა შემოწმებაც დაიწყოს:

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. *Repository access* → **Only select repositories** → აირჩიე `analyst-Positions.`.
3. *Permissions* → **Actions: Read and write**.
4. აპში დააჭირე ⚙️ და ჩასვი ტოკენი. ტოკენი ინახება მხოლოდ შენს ტელეფონზე.

## ცნობილი შეზღუდვები

- **jobs.ss.ge** ავტომატურ წაკითხვას ბლოკავს. **worknet.gov.ge** და **hr.gov.ge** საზღვარგარეთიდან (GitHub-ის სერვერებიდან) მიუწვდომელია. ამიტომ ეს სამი სიაში არ არის.
- შეჯამებას ქმნის უფასო, წესებზე დაფუძნებული ამომღები. ზოგი განცხადება თავად საიტზე მხოლოდ კომპანიის საკარიერო გვერდის ბმულს შეიცავს. ასეთ ვაკანსიაზე „მოკლედ“ ცოტა ინფორმაციას აჩვენებს, ღილაკი „ორიგინალი“ კი სრულ აღწერას გახსნის.
- თუ რეპოში 60 დღე არაფერი შეიცვალა, GitHub დაგეგმილ შემოწმებას ავტომატურად აჩერებს. მონაცემების ყოველდღიური ჩაწერა, როგორც წესი, ამას აკავებს. თუ მაინც შეჩერდა, GitHub ელფოსტით გაგაფრთხილებს და ერთი დაჭერით ჩართავ.
